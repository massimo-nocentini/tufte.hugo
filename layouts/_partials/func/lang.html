{{- /* Describes a language through the Language methods Name, Label, Locale and Direction (the deprecated Lang, LanguageName, LanguageCode and LanguageDirection warn), with the theme's defaults in one place. Takes: a language (site.Language, or .Language of a page). Returns: a dict name the language key, e.g. "en" label the display name (languageName / label; default: the key) locale the BCP 47 tag for lang/hreflang (languageCode / locale; default: the key) dir "ltr", "rtl" or "" (not configured) */ -}} {{- $l := . -}} {{- $out := dict "name" "" "label" "" "locale" "" "dir" "" -}} {{- with $l -}} {{- $name := printf "%v" .Name -}} {{- $out = dict "name" $name "label" (printf "%v" (.Label | default $name)) "locale" (printf "%v" (.Locale | default $name)) "dir" (printf "%v" (.Direction | default "")) -}} {{- end -}} {{- return $out -}}
