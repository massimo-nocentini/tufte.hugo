{{- /* Formats a date with the site "dateFormat" param. Empty (the theme default): the language's i18n key dateFormat, which is ":date_long" in all five theme files: Hugo's localized long date ("March 5, 2024", "5 marzo 2024", "5. März 2024", "5 de marzo de 2024", "2024年3月5日"), so the order of day and month follows the language. A language without the key (no theme or site i18n file) gets the English value through func/t.html, ":date_long" too; with no value at all, ":date_long". Any Go time layout or Hugo localized token (":date_long", ":date_medium") works; month and day names follow the site language. Takes: a time.Time value, or a dict with "date" - the time.Time value, "format" - optional layout overriding the "dateFormat" param. Returns: the formatted string, or "" for a zero or missing date. */ -}} {{- $date := . -}} {{- $format := site.Params.dateFormat | default (partial "func/t.html" "dateFormat") | default ":date_long" -}} {{- if reflect.IsMap . -}} {{- $date = .date -}} {{- with .format }}{{ $format = . }}{{ end -}} {{- end -}} {{- $out := "" -}} {{- with $date -}} {{- if not .IsZero -}} {{- /* Some locales have no abbreviated month or weekday name in the CLDR data of recent Hugo (0.169: "Jan" is "" in Japanese, Korean and Arabic, "Mon" in Arabic and Persian), which would leave " 5" for "Jan 2": the full name is used instead. Hugo's own ":date_*" tokens are left alone. */ -}} {{- $f := $format -}} {{- if not (hasPrefix $f ":") -}} {{- if and (findRE `Jan` (replace $f "January" "") 1) (not (strings.TrimSpace (time.Format "Jan" .))) -}} {{- $f = replaceRE `January|Jan` "January" $f -}} {{- end -}} {{- if and (findRE `Mon` (replace $f "Monday" "") 1) (not (strings.TrimSpace (time.Format "Mon" .))) -}} {{- $f = replaceRE `Monday|Mon` "Monday" $f -}} {{- end -}} {{- end -}} {{- $out = time.Format $f . -}} {{- end -}} {{- end -}} {{- return $out -}}
