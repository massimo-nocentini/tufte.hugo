{{- /* Counter offsets of a page (SPEC-LATEX §4.1, §6.5): inside a book with book.continuous on (the default), the sums of tufte/counts.html over the pages printed before it in the whole-book document (list.print.html), so sidenote, figure, table, listing and equation numbers run through the whole book and every page shows the numbers the print document shows. That reading order is: 1. the book landing (its own body; the title page's \thanks take no number, as tufte-book's \maketitlepage prints \thanklesstitle and swallows them; without a title page, book.titlepage = false, the \maketitle block's \thanks are notes 1..k), 2. the chapters in reading order, each part page (\part, with its own content) right before the first chapter of the part, and the parts without chapters at their place (tufte/book/sequence.html). With book.continuous = false: sidenotes restart on every page (the print document resets their counter per chapter and part); figures, tables, listings and equations restart in each numbered chapter, with the prefix "N." (book.numberChapters), and a part page, an unnumbered chapter or the front or back matter continues the counters of the last numbered chapter before it, as \part and \chapter* do in LaTeX (tufte/book/local-offset-map.html). Zeros otherwise: handouts, and the book landing itself (it comes first). Takes: a page. Returns: dict sidenote figure table listing eq (ints), prefix (the float and equation number prefix, "N." or "": continuous = false only). Callers: partialCached "tufte/offsets.html" $p (or $p.RelPermalink $p.Path) */ -}} {{- /* Memoized in the page's Store for the current build: see tufte/opts.html. */ -}} {{- $memoRes := false -}} {{- with partial "tufte/memo.html" (dict "page" . "key" "tufteMemoOffsets") -}} {{- $memoRes = .v -}} {{- else -}} {{- $p := . -}} {{- $sn := 0 -}}{{- $fig := 0 -}}{{- $tab := 0 -}}{{- $lst := 0 -}}{{- $eq := 0 -}} {{- $prefix := "" -}} {{- with partialCached "tufte/book/root.html" $p (or $p.RelPermalink $p.Path) -}} {{- $root := . -}} {{- $continuous := partial "tufte/truthy.html" (partialCached "tufte/opt.html" (dict "page" $p "key" "book.continuous") (or $p.RelPermalink $p.Path) "book.continuous") -}} {{- if and (ne $root $p) (not $continuous) -}} {{- /* Per-chapter counters: a numbered chapter starts at "N.1", a page that does not step the chapter counter continues the last numbered chapter (tufte/book/local-offset-map.html). */ -}} {{- $map := partialCached "tufte/book/local-offset-map.html" $root (or $root.RelPermalink $root.Path) -}} {{- with index $map (printf "%s|%s" $p.Path (or $p.RelPermalink "")) -}} {{- $fig = .figure -}} {{- $tab = .table -}} {{- $lst = .listing -}} {{- $eq = .eq -}} {{- $prefix = .prefix -}} {{- end -}} {{- end -}} {{- if and (ne $root $p) $continuous -}} {{- /* The running sums over the print order (same walk as list.print.html), computed once per book. */ -}} {{- $map := partialCached "tufte/book/offset-map.html" $root (or $root.RelPermalink $root.Path) -}} {{- with index $map (printf "%s|%s" $p.Path (or $p.RelPermalink "")) -}} {{- $sn = .sidenote -}} {{- $fig = .figure -}} {{- $tab = .table -}} {{- $lst = .listing -}} {{- $eq = .eq -}} {{- end -}} {{- end -}} {{- end -}} {{- $memoRes = dict "sidenote" $sn "figure" $fig "table" $tab "listing" $lst "eq" $eq "prefix" $prefix -}} {{- $p.Store.Set "tufteMemoOffsets" (dict "v" $memoRes "b" (partialCached "tufte/build-stamp.html" "stamp" "stamp")) -}} {{- end -}} {{- return $memoRes -}}
