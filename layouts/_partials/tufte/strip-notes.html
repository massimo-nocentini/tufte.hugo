{{- /* Removes margin material from a piece of phase-1 HTML, for the names tufte/labels.html records (a heading's or a run-in paragraph's title, used by xref "name"/"page" and as the "where" of later labels): margin-toggle label/input pairs, sidenotes, margin notes, citation blocks and real-footnote markers (span.tufte-fn: the footnote shortcode, cite as=footnote and Markdown footnotes kept as footnotes) with their nested spans (math, small caps, a citation's own spans), and the sn-end/fn-end markers. A margin note has no sn-end marker (marginnote.html), so the end of each note is found by balancing its spans, as tufte/resolve-refs.html and tufte/lists/render.html do: note spans are renamed , then innermost elements are resolved repeatedly (finished spans become , finished notes are removed). Takes: the HTML (string). Returns: the HTML without margin material (string). */ -}} {{- $h := string . -}} {{- $h = replaceRE `]*>[^<]*]*/?>` "" $h -}} {{- if findRE `]*>%s(?:)?` $C) "" $h -}} {{- $h = replaceRE (printf `]*)>(%s)` $C) "$2" $h -}} {{- end -}} {{- $h = replace (replace $h "" "" -}} {{- end -}} {{- $h = replaceRE `` "" $h -}} {{- return $h -}}
