{{- /* Gathers the citations of a note or caption into one citation block at its end, as tufte-latex does: inside \sidenote, \marginnote and \caption, \cite only collects its keys, and \@tufte@print@citations prints them all after the note, joined "E1; E2; and E3" (SPEC-LATEX §3.7). A cite nested in a holder (cite.html) emits, through the nest protocol, ENTRIES where it stands. The holder (sidenote, marginnote, footnotetext, footnote, marginblock, and every float through tufte/figure.html) passes its rendered text here: the nested blocks are cut out (with the white space before them, so "see {{< cite "x" >}}." reads "see.") and merged, after them the references of the holder's own cite= parameter. With bibliography.margin = false (class option nobib), tufte-latex uses the standard \cite everywhere (tufte-common.def redefines it in notes and captions only when natbib is loaded): the cite= keys become the bracketed list numbers of cite.html, " […, …]", returned as the block (after the text, outside any citation-block), so postprocess numbers and links them like every other nobib citation. A nested cite already is "[n]" in that mode (cite.html), never a block. Takes a dict: page the page (its bibliography database) required html the rendered text (string) keys optional slice of extra keys (the cite= parameter), lowercased Returns: dict html the text without the nested blocks block E1; E2; and E3, or "" when there is no citation (nobib: " [n, m]" for the cite= keys) */ -}} {{- $html := string (.html | default "") -}} {{- $pieces := slice -}} {{- $re := `(?s)\s*(.*?)` -}} {{- if strings.Contains $html `class="cite-end"` -}} {{- range findRESubmatch $re $html -}} {{- $pieces = $pieces | append (index . 1) -}} {{- end -}} {{- $html = replaceRE $re "" $html -}} {{- end -}} {{- $nobib := "" -}} {{- with .keys -}} {{- $p := $.page -}} {{- $margin := partial "tufte/truthy.html" (partialCached "tufte/opt.html" (dict "page" $p "key" "bibliography.margin") (or $p.RelPermalink $p.Path) "bibliography.margin") -}} {{- if $margin -}} {{- $pieces = $pieces | append (string (partial "tufte/bib/entries.html" (dict "page" $p "keys" . "postnote" ""))) -}} {{- else -}} {{- $refs := slice -}} {{- range . -}} {{- $refs = $refs | append (printf `` (htmlEscape .) (htmlEscape .) (htmlEscape .)) -}} {{- end -}} {{- $nobib = printf ` [%s]` (delimit $refs ", ") -}} {{- end -}} {{- end -}} {{- $block := "" -}} {{- if eq (len $pieces) 1 -}} {{- $block = index $pieces 0 -}} {{- else if gt (len $pieces) 1 -}} {{- /* Each piece is "E1", "E1; and E2" or "E1; E2; and E3" (entries.html): drop the inner "and", join, and put one "and" before the last. */ -}} {{- $and := partial "func/t.html" "and" | default "and" -}} {{- $sep := `; %s` . -}} {{- end -}} {{- $block = printf "%s%s" $block $nobib -}} {{- return (dict "html" $html "block" $block) -}}
