{{- /* The plain text of a rendered caption, for an attribute that names the float: a figure's alt text (tufte/figure.html), a video's aria-label (the video shortcode). Math: server KaTeX output reads as its TeX ($x^2$, the TeX annotation of its MathML copy). The rest of the MathML copy and the visual HTML (span.katex-html, whose text is in layout order: \frac{a}{b} would read "ba") are left out. Also left out, as not part of the caption's wording: the toggles (label/input, "⊕"), end-of-proof symbols and the nested sidenotes, margin notes, notes in notes, citation blocks and real-footnote markers (span.tufte-fn) (spans balanced, so their own nested spans do not end them early). Cross-reference markers are kept as they are: the caller escapes them into the attribute and tufte/postprocess.html replaces the escaped marker with the resolved text ("Table 1"), as in the visible caption. Where a note or citation was dropped and the kept text goes on with punctuation (`Caption {{< cite "k" >}}.`), the space written before the dropped element goes too ("Caption.", as the visible caption reads): only at these points, so a code span keeps its own spaces. So are the number tokens of a theorem in the caption (SPEC-THM; tufte/resolve-refs.html fills the escaped copy with the plain number) and nobib citation numbers (cite-num spans, "[2]") and plainnat's extra-letter markers (bib-extra spans, the "a" of "1999a"): postprocess fills the escaped span as it fills the visible one (tufte/bib/fill-extra.html). A shortcode placeholder still in the caption is dropped: it must not reach the attribute, where Hugo would put the shortcode's HTML. (tufte/figure.html does not call this partial on such a caption, a Markdown image title or table caption= holding a shortcode: it defers the alt text, which func/content-raw.html fills from the caption once the shortcode has run.) Takes: the caption HTML (string or template.HTML). Returns: the plain text (string; not escaped, the markers above raw). */ -}} {{- $buf := "" -}} {{- $depth := 0 -}} {{- $skip := 0 -}} {{- $inLabel := false -}} {{- $inTex := false -}} {{- $skipMath := false -}} {{- $cut := false -}} {{- $noteSkip := false -}} {{- range $t := findRE `(?s)]*>[^<]*|]*>|]*>|<[^>]*>|[^<]+` (string .) -}} {{- if eq $t `` -}} {{- /* only the formula's own (not one in a skipped note or label) */ -}} {{- $inTex = and $skipMath (not $inLabel) -}} {{- else if and $inTex (not (strings.HasPrefix $t "<")) -}} {{- $buf = printf "%s$%s$" $buf (strings.TrimSpace (htmlUnescape $t)) -}} {{- else if eq $t "" -}} {{- $inTex = false -}} {{- else if or (strings.HasPrefix $t `" -}} {{- if eq $skip $depth }}{{ $skip = 0 }}{{ $cut = $noteSkip }}{{ end -}} {{- $depth = sub $depth 1 -}} {{- else if strings.HasPrefix $t "" -}} {{- $inLabel = false -}} {{- else if or (gt $skip 0) $inLabel -}} {{- else if strings.HasPrefix $t `}}." reads "Md caption.") */ -}} {{- $buf = $buf | replaceRE `\s*HAHAHUGOSHORTCODE\w*?HBHB\s*([.,;:!?)])` "$1" | replaceRE `HAHAHUGOSHORTCODE\w*?HBHB` "" | replaceRE `\s+` " " | strings.TrimSpace -}} {{- return $buf -}}
