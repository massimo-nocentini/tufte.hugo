{{- /* Resolves the deferred attributes of the image and link render hooks: an image's alt text whose Markdown holds a shortcode, a nest token, a footnote reference [^x] or other markup that is not plain text, and a link title that holds a shortcode or a nest token. Inside a hook a shortcode is still Hugo's placeholder (or, in a theme shortcode's inner text, a nest token): written into the attribute, it would be replaced by the shortcode's HTML there and break the tag. So the hook writes a token in the attribute and the text after the element: …TEXT …TEXT (key: 12 hex digits; TEXT: the rendered alt text, or the escaped title). Once the shortcodes' HTML is in place, TEXT is split by tufte/img-tip.html: its plain text (math as its TeX source, cross-reference markers kept for postprocess) replaces the token, and its notes, citations and footnote markers follow the element (the img, after its own title mark if any; the ), so a [^x] in an alt text is still a footnote of the page and a cite still a citation sidenote. data-in="note": the img is inside a margin note (a margin figure), so those notes are cleaned like a caption's (tufte/note-in-note.html, tufte/cite-gather.html). Callers: func/content-raw.html (page-level Markdown, after Hugo put the shortcodes' output in place; final = true removes leftovers) and tufte/render-inner.html (a theme shortcode's inner text, once its nest tokens are swapped). Takes a dict: page the page required html the HTML (string or template.HTML) final bool: drop the marks and tokens left unresolved Returns: the HTML string. */ -}} {{- $page := .page -}} {{- $html := string (.html | default "") -}} {{- if strings.Contains $html `(.*?)` -}} {{- range findRESubmatch $markRE $html -}} {{- $mark := index . 0 -}} {{- $tok := printf "TUFTEATTR%sEND" (index . 1) -}} {{- {{- if strings.Contains $notes `class="margin-toggle` -}} {{- $notes = partial "tufte/note-in-note.html" (dict "page" $page "html" $notes "holder" "margin figure's alt text" "where" $at) -}} {{- end end -}} {{- end -}} {{- if strings.Contains $html $mark -}} {{- $target := "" -}} {{- if $notes -}} {{- $re := printf `(?s)]*\stitle="%s"[^>]*>.*?` $tok -}} {{- if eq (index . 2) "img" -}} {{- $re =
