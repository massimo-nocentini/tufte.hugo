{{- /* The text of one contents entry (page TOC, book contents), as inline HTML that may sit inside the entry's : 1. Links of the heading text are unwrapped (Hugo 0.146's .TableOfContents keeps them, and an inside the entry's splits the entry in a browser). 2. Math: Hugo builds the TOC texts (.TableOfContents, .Fragments) from the Markdown source before the passthrough render hook runs, so a formula in a heading comes out as raw TeX ($\alpha$, Hugo 0.169) or is dropped (Hugo 0.146). When the page has math (Store "hasMath", set by render-passthrough.html), the heading with this id is looked up in the page's phase-1 HTML (func/content-raw.html) and, when it holds typeset math (KaTeX output, or the client engine's span.math), its rendered inner HTML is used instead, cleaned like the TOC texts: no heading anchor, number tokens, index or label anchors, margin toggles, notes or links. The math is then the one of the heading (server KaTeX, or span.math for the browser's auto-render). 3. Shortcodes: Hugo builds those texts before shortcodes run too, and the callers remove the shortcode placeholders, so the words a shortcode prints (the NASA of a smallcaps shortcode, an xref number) would be lost. When the caller says a placeholder was removed (shortcode = true), the rendered heading is used the same way, whatever it holds; the extra letter of an author-year citation (1999a) is filled in (tufte/bib/fill-extra.html). Takes: a dict with page the page holding the heading id the heading id (as render-heading.html writes it) text the entry text from Hugo's TOC, margin material already removed shortcode optional: true when the text held a shortcode placeholder nth optional: which of the headings with this id (default 1) xinner optional: true for a heading of a shortcode's inner text with an explicit id (marked data-tufte-xinner by tufte/render-inner.html); nth then counts those only, and otherwise they are skipped Returns: string (HTML). */ -}} {{- $p := .page -}} {{- $text := replaceRE `]*>` "" (string .text) -}} {{- if and .id $p -}} {{- $raw := partialCached "func/content-raw.html" (dict "page" $p "summary" false) (or $p.RelPermalink $p.Path) false | string -}} {{- $sc := eq .shortcode true -}} {{- if or $sc ($p.Store.Get "hasMath") -}} {{- /* The nth heading with this id (headings that differ only by their shortcodes share one, tufte/heading-id.html). */ -}} {{- $nth := int (.nth | default 1) -}} {{- $parts := split $raw (printf ` id="%s"` .id) -}} {{- $after := "" }}{{ $seen := 0 -}} {{- $hre := cond (eq .xinner true) `]*>(.*?).*$` "$1" $after -}} {{- if or $sc (findRE `class="(?:katex|math math-inline|math-error)` $inner 1) -}} {{- $t := $inner -}} {{- $t = replaceRE `]*>[^<]*` "" $t -}} {{- /* Phase 1 is unresolved: notes, citation blocks and real-footnote markers (span.tufte-fn, whose text may hold paragraphs) go (tufte/strip-notes.html), and xref markers get their text, as in the heading (tufte/resolve-refs.html; the page itself reports undefined keys). */ -}} {{- $t = partial "tufte/strip-notes.html" $t -}} {{- if strings.Contains $t `class="xref"` -}} {{- $t = partial "tufte/resolve-refs.html" (dict "page" $p "html" $t "quiet" true) -}} {{- end -}} {{- $t = replaceRE `]*>[^<]*]*/?>` "" $t -}} {{- /* a lone toggle: footnotemark (its input is in the footnotetext) */ -}} {{- $t = replaceRE `` "" $t -}} {{- $t = replaceRE `(?s)]*>.*?` "" $t -}} {{- $t = replaceRE `]*>[^<]*` "" $t -}} {{- $t = replaceRE `` "" $t -}} {{- $t = replaceRE `]*>` "" $t -}} {{- $t = replaceRE `\s+id="[^"]*"` "" $t -}} {{- /* plainnat's extra letters (1999a) of author-year citations: only postprocess fills them in the body. */ -}} {{- if strings.Contains $t "bib-extra" -}} {{- $t = partial "tufte/bib/fill-extra.html" (dict "page" $p "html" $t) -}} {{- end -}} {{- $text = strings.TrimSpace $t -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $text -}}
