{{- /* The frontispiece of a book: the illustration on the page facing the title page (tufte-book's front matter, page ii). Front matter `frontispiece` of the book root: frontispiece: {src: front.png, alt: "…", caption: "…"} (or just a src string) src is resolved like the figure shortcode's (a resource of the book root's bundle, then assets/, then a static/ path or a URL); caption is inline Markdown, set in the margin as for a main figure; alt defaults to the plain caption. The frontispiece is never numbered (it is not a Figure of the lists of figures).
The figure is made in phase 1 with the page content (tufte/book/front-fields.html), so the caption's notes, footnotes, citations and cross-references (and the alt text derived from it) are resolved with the landing's. Takes: the book root page (the processed frontispiece), or a dict {page, render: true} (tufte/book/front-fields.html: the phase-1 HTML). */ -}} {{- $p := . -}} {{- $render := false -}} {{- if reflect.IsMap . }}{{ $p = .page }}{{ $render = eq .render true }}{{ end -}} {{- if not $render -}} {{- partial "tufte/book/front-fields.html" (dict "page" $p "slot" "frontispiece") | safeHTML -}} {{- else -}} {{- with $p.Params.frontispiece -}} {{- $src := "" }}{{ $alt := "" }}{{ $caption := "" -}} {{- if reflect.IsMap . -}} {{- $src = printf "%v" (.src | default "") -}} {{- $alt = printf "%v" (.alt | default "") -}} {{- $caption = printf "%v" (.caption | default "") -}} {{- else -}} {{- $src = printf "%v" . -}} {{- end -}} {{- with strings.TrimSpace $src -}} {{- $fig := partial "tufte/figure.html" (dict "Page" $p "Src" . "Alt" $alt "Caption" (partial "tufte/book/fn-local.html" (dict "text" $caption "tag" "fp")) "Type" "main" "Numbered" false) }}
{{ $fig | safeHTML }}
{{- end -}} {{- end -}} {{- end -}}
