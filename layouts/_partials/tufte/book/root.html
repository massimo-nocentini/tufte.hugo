{{- /* The book a page belongs to (SPEC-LATEX §4.1). A book is a section whose _index.md sets `book: true`, or the home page when content/_index.md sets it (the whole site is one book: its top-level regular pages are the chapters, its top-level sections the parts). The root is the page itself when it is such a section (or that home page), else the nearest ancestor that is. Taxonomy and term pages (tags, categories) are never in a book: their ancestor is the home page, but they are not chapters. A book inside a book is not a book of its own: the outermost `book: true` wins, so the inner section is a part of the outer book (its numbers, contents, navigation and print.html agree), and tufte/book/chapters.html warns (tufte-book-structure). A page with `build: {list: never}` is in no page collection, hence in no book: it renders as an ordinary page. Takes: a page. Returns: the book root page, or false. Callers: partialCached "tufte/book/root.html" $p (or $p.RelPermalink $p.Path) */ -}} {{- $root := false -}} {{- $p := . -}} {{- if in (slice "home" "section" "page") $p.Kind -}} {{- if and (or $p.IsSection $p.IsHome) (partial "tufte/truthy.html" (index $p.Params "book")) -}} {{- $root = $p -}} {{- end -}} {{- /* Ancestors run from the parent up to the home page: the last match is the outermost book. */ -}} {{- range $p.Ancestors -}} {{- if and (or .IsSection .IsHome) (partial "tufte/truthy.html" (index .Params "book")) -}} {{- $root = . -}} {{- end -}} {{- end -}} {{- /* A page that is not in the book's reading order is not a chapter: one with `build: {list: never}` is in no page collection, so tufte/book/chapters.html (the root's RegularPages and each part's RegularPagesRecursive) cannot number it, give it labels or link it from the navigation; it is an ordinary page. The same collections as there (a part is the ancestor that is a child of the root). */ -}} {{- if and $root (eq $p.Kind "page") -}} {{- $coll := $root.RegularPages -}} {{- if ne $p.Parent $root -}} {{- range $p.Ancestors }}{{ if eq .Parent $root }}{{ $coll = .RegularPagesRecursive }}{{ end }}{{ end -}} {{- end -}} {{- if not (in $coll $p) }}{{ $root = false }}{{ end -}} {{- end -}} {{- end -}} {{- return $root -}}
