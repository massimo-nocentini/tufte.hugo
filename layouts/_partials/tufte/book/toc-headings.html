{{- /* The sections of one chapter for the book contents (tocdepth 1):
  1. Section
    2. …
A chapter that is never rendered (build.render = never) has no URL: its sections get the placeholder links of tufte/page-link.html (), plain text on the website and in-document links in the book's print document, where the chapter is printed (tufte/book/print-links.html), as its title gets. Walks the .Fragments.Headings tree of the chapter and keeps the nodes with Level 2 and a non-empty ID (h2 = \section), at any depth of the tree (the tree starts at h1 when the content has one). Margin material and Hugo's shortcode placeholders are removed from the heading texts (R27), and the ids are cleaned like render-heading.html's (tufte/heading-anchor.html). A heading with math gets its typeset formula, and a heading that held a shortcode its rendered text (tufte/toc-text.html). The h2 of a shortcode's inner text (fullwidth, details…), which .Fragments never sees but which is numbered like the others, is added in document order (tufte/content-headings.html), so the section numbers of the contents do not skip. Takes: a dict with page the chapter page headings a tableofcontents.Headings slice (the walk recurses on it) inner internal: true in the recursive calls (no
    wrapper) seen internal: the Scratch that counts the ids met so far Returns: template.HTML ("" when there are no sections). */ -}} {{- $p := .page -}} {{- /* How many headings with each id came before (document order: a preorder walk of the tree, every level), so that the nth heading with an id that several share (headings that differ only by their shortcodes, tufte/heading-id.html) reads its own text. */ -}} {{- $seen := .seen | default newScratch -}} {{- $items := "" -}} {{- range .headings -}} {{- $id := "" -}} {{- $nth := 1 -}} {{- with .ID -}} {{- $id = partial "tufte/heading-anchor.html" (dict "page" $p "id" .) -}} {{- $seen.Add (printf "id:%s" $id) 1 -}} {{- $nth = $seen.Get (printf "id:%s" $id) -}} {{- end -}} {{- if and (eq .Level 2) $id -}} {{- $t := string .Title -}} {{- $hasSC := strings.Contains $t "HAHAHUGOSHORTCODE" -}} {{- $t = replaceRE `]*>[^<]*]*/?>` "" $t -}} {{- /* a lone toggle: footnotemark (its input is in the footnotetext) */ -}} {{- $t = replaceRE `` "" $t -}} {{- $t = replaceRE `(?s)]*>.*?` "" $t -}} {{- $t = replaceRE `]*>[^<]*` "" $t -}} {{- $t = replaceRE `` "" $t -}} {{- $t = replaceRE `]*>` "" $t -}} {{- /* Hugo's shortcode placeholders (headings holding a shortcode): the id is cleaned as render-heading.html cleans it (above). */ -}} {{- $t = replaceRE `\s*HAHAHUGOSHORTCODE[0-9A-Za-z]*?HBHB` "" $t -}} {{- /* Math in the heading: the typeset formula; a heading that held a shortcode: the rendered text, with the words the shortcode prints (tufte/toc-text.html). */ -}} {{- $t = partial "tufte/toc-text.html" (dict "page" $p "id" $id "text" (strings.TrimSpace $t) "shortcode" $hasSC "nth" $nth) -}} {{- /* Headings renamed ID-2… (an explicit id written on two headings, or an automatic id that an explicit one repeats: tufte/labels.html "htoc", by position among the headings of .Fragments). */ -}} {{- $href := $id -}} {{- with index ((partialCached "tufte/labels.html" $p (or $p.RelPermalink $p.Path)).htoc | default dict) $id -}} {{- if le $nth (len .) }}{{ with index . (sub $nth 1) }}{{ $href = . }}{{ end }}{{ end -}} {{- end -}} {{- $items = printf `%s
  1. %s
    2. ` $items (partial "tufte/page-link.html" (dict "page" $p "anchor" $href "html" $t "book" true)) -}} {{- end -}} {{- /* Deeper levels: h2 below an h1 are listed; the subheadings of an h2 list nothing but are counted. */ -}} {{- with .Headings -}} {{- $items = printf "%s%s" $items (partial "tufte/book/toc-headings.html" (dict "page" $p "headings" . "inner" true "seen" $seen) | string) -}} {{- end -}} {{- end -}} {{- if not .inner -}} {{- $ch := partialCached "tufte/content-headings.html" $p (or $p.RelPermalink $p.Path) -}} {{- if $ch.inner -}} {{- $old := findRE `(?s)
  2. ]*>.*?
    3. ` $items -}} {{- $new := "" -}} {{- $i := 0 -}} {{- range $ch.headings -}} {{- if eq .level 2 -}} {{- if .inner -}} {{- $t := partial "tufte/toc-text.html" (dict "page" $p "id" (.tid | default .id) "text" "" "shortcode" true "nth" (.tnth | default 1) "xinner" (eq .xinner true)) -}} {{- $new = printf `%s
  3. %s
    4. ` $new (partial "tufte/page-link.html" (dict "page" $p "anchor" .id "html" $t "book" true)) -}} {{- else if lt $i (len $old) -}} {{- $new = printf "%s%s" $new (index $old $i) -}} {{- $i = add $i 1 -}} {{- end -}} {{- end -}} {{- end -}} {{- range after $i $old }}{{ $new = printf "%s%s" $new . }}{{ end -}} {{- $items = $new -}} {{- end -}} {{- end -}} {{- $out := $items -}} {{- if and (not .inner) $items -}} {{- $out = printf `
