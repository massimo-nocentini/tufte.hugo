{{- /* Chapter epigraph (block). Put it on its own lines. Two forms: 1. One quote, attribution from params, inner text is block Markdown: {{< epigraph author="Richard P. Feynman" cite="“What Do You Care What Other People Think?”" >}} For a successful technology, reality must take precedence over public relations … {{< /epigraph >}} 2. Several quotes: the inner text holds Markdown block quotes (attribution via block attributes, see the blockquote render hook) or nested blockquote shortcodes: {{< epigraph >}} > The English language … foolish thoughts. {author="George Orwell" cite="Politics and the English Language"} > For a successful technology, reality must take precedence … {author="Richard P. Feynman"} {{< /epigraph >}} style="open" gives the book's opening-epigraph look (\openepigraph: sans-serif capitals, class open-epigraph). Params (form 1, all optional): author, cite (work title, in ; alias work, as in a book root's `epigraphs:` list), url (blockquote cite attribute; links the footer), footer (full footer, inline Markdown), class (extra classes for the div), style. In form 2 only class and style apply; author/cite/url/footer are ignored with a warning. Output (Tufte CSS):

…

Author, Work
*/ -}} {{- $p := .Page -}} {{- $text := strings.TrimSpace .Inner -}} {{- /* Block Markdown; nested shortcodes are kept (nest tokens). */ -}} {{- $html := partial "tufte/render-inner.html" (dict "page" $p "inner" $text "display" "block" "where" (printf "%s shortcode in %v" .Name .Position)) | string -}} {{- $author := "" -}}{{- $cite := "" -}}{{- $url := "" -}}{{- $footerRaw := "" -}}{{- $class := "" -}}{{- $style := "" -}} {{- if .IsNamedParams -}} {{- $author = .Get "author" | default "" -}} {{- $cite = .Get "cite" | default (.Get "work") | default "" -}} {{- $url = .Get "url" | default "" -}} {{- $footerRaw = .Get "footer" | default "" -}} {{- $class = printf "%v" (.Get "class" | default "") | strings.TrimSpace -}} {{- $style = lower (printf "%v" (.Get "style" | default "")) -}} {{- end -}} {{- /* Form 2 when the content already is (a list of) block quotes. */ -}} {{- $multi := or (strings.HasPrefix $text ">") (strings.HasPrefix $html " (%s)" .Position -}} {{- end -}} {{- $divClass := "epigraph" -}} {{- if eq $style "open" -}} {{- $divClass = "epigraph open-epigraph" -}} {{- else if $style -}} {{- warnidf "tufte-bad-option" "epigraph shortcode: style must be \"open\" or empty, not %q (%s)" $style .Position -}} {{- end -}} {{- with $class }}{{ $divClass = printf "%s %s" $divClass . }}{{ end -}} {{- $out := "" -}} {{- if $multi -}} {{- $out = printf "
\n%s\n
" (htmlEscape $divClass) $html -}} {{- else -}} {{- $bq := partial "tufte/quote.html" (dict "page" $p "html" $html "author" $author "cite" $cite "url" $url "footer" $footerRaw "class" "") -}} {{- $out = printf "
%s
" (htmlEscape $divClass) $bq -}} {{- end -}} {{- partial "tufte/nest.html" (dict "ctx" . "html" $out) | safeHTML -}}
