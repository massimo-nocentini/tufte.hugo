{{- /* Footnote mark without its text (inline; \footnotemark), for places where a note cannot sit (a table cell, a heading): the text goes in a matching footnotetext, placed after the table or paragraph. | Front matter{{< footnotemark "fm" >}} | … | … {{< footnotetext "fm" >}}The front matter of a book …{{< /footnotetext >}} Positional: the name; or named: name="fm". The name only pairs the mark with its text (tufte/ft-name.html). A name may be used again: each footnotetext takes the marks of its name written since the previous footnotetext of that name (func/content-raw.html numbers the ids: NAME, NAME.2, NAME.3…), so two tables can each use "w". No other numbered sidenote may sit between the mark and its text: the number shown next to the text is the current value of the sidenote counter, as in LaTeX. Output: (data-ft: a note id, func/note-id.html, so that two marks of one name are two different tags: tufte/counts.html and tufte/labels.html count each distinct mark once, and each steps the sidenote counter). */ -}} {{- $name := "" -}} {{- if .IsNamedParams -}} {{- $name = printf "%v" (.Get "name" | default "") -}} {{- else -}} {{- $name = printf "%v" (.Get 0 | default "") -}} {{- end -}} {{- $name = partial "tufte/ft-name.html" $name -}} {{- if not $name -}} {{- errorf "footnotemark shortcode: a name is required, e.g. {{< footnotemark \"fm\" >}} (%s)" .Position -}} {{- end -}} {{- $hash := substr (md5 (or .Page.RelPermalink .Page.Path)) 0 6 -}} {{- $out := printf `` $hash $name (partial "func/note-id.html" .Page) -}} {{- partial "tufte/nest.html" (dict "ctx" . "html" $out) | safeHTML -}}
