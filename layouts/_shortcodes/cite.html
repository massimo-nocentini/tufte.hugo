{{- /* Citation (inline; \cite). The full reference goes in the margin as a numbered sidenote, as tufte-latex does: … as Tufte argues{{< cite "tufte2006" >}}. {{< cite "tufte2006,tufte1990" >}} several keys {{< cite "tufte2006" "tufte1990" >}} several keys {{< cite keys="tufte2006" page="42" offset="-1bl" >}} Keys are looked up (case-insensitively) in the bibliography database (data/bibliography.*, the page's `bibliography` file and `references`). Named params (never mixed with positional ones): keys comma-separated keys offset vertical shift of the note (\cite[offset]{…}): "-1bl", "1rem" page a page number: ", p. 42" after the (last) reference; a range or list ("42-45", "42, 45") gives ", pp. 42–45" (en dash); the abbreviation is translated (i18n bibPageAbbr, bibPagesAbbr) note a free postnote: ", NOTE"; with page too, it follows the page locator: ", p. 42, NOTE" as "sidenote" (default; site/page option citeAs) | "footnote": the references go in a real footnote below the text (SPEC-LATEX §11) mode "margin" (default) | "text" (Author (Year)) | "paren" ((Author Year)) | "author" | "year": inline text, no sidenote (natbib) Inside a sidenote, margin note, footnote, footnotetext, margin block, fig caption, float caption or margintable/listing/subfigures float, the references are gathered under that note or caption, in one citation block after its text, with those of its cite= parameter (\cite inside \sidenote, \marginnote, \caption: tufte-common.def collects the keys and prints them after the note). See tufte/cite-gather.html. A cite in a cell of a table or fullwidthtable is not gathered: it stays a numbered sidenote in the cell, as in a Markdown table. With params.tufte.bibliography.margin = false (class option nobib) a citation is a bracketed number "[3]" linked to the list of references. Output, margin mode (SPEC-LATEX §3.7): ENTRIES */ -}} {{- $p := .Page -}} {{- $raw := slice -}} {{- $as := "" -}} {{- $offset := "" -}}{{- $pageNo := "" -}}{{- $noteText := "" -}}{{- $mode := "margin" -}} {{- if .IsNamedParams -}} {{- $raw = $raw | append (printf "%v" (.Get "keys" | default (.Get "key") | default "")) -}} {{- $offset = printf "%v" (.Get "offset" | default "") -}} {{- $pageNo = printf "%v" (.Get "page" | default "") | strings.TrimSpace -}} {{- $noteText = printf "%v" (.Get "note" | default "") | strings.TrimSpace -}} {{- $mode = lower (printf "%v" (.Get "mode" | default "margin")) -}} {{- $as = lower (printf "%v" (.Get "as" | default "")) -}} {{- else -}} {{- range .Params }}{{ $raw = $raw | append (printf "%v" .) }}{{ end -}} {{- end -}} {{- $keys := slice -}} {{- range $raw -}} {{- range split . "," -}} {{- with strings.TrimSpace . | lower -}} {{- if not (in $keys .) }}{{ $keys = $keys | append . }}{{ end -}} {{- end -}} {{- end -}} {{- end -}} {{- if not $keys -}} {{- errorf "cite shortcode: no citation key, e.g. {{< cite \"tufte2006\" >}} (%s)" .Position -}} {{- end -}} {{- if not (in (slice "margin" "text" "paren" "author" "year") $mode) -}} {{- warnidf "tufte-bad-option" "cite shortcode: mode must be margin, text, paren, author or year, not %q; using margin (%s)" $mode .Position -}} {{- $mode = "margin" -}} {{- end -}} {{- if not $as -}} {{- $as = lower (printf "%v" (partialCached "tufte/opt.html" (dict "page" $p "key" "citeas" "default" "sidenote") (or $p.RelPermalink $p.Path) "citeas" | default "sidenote")) -}} {{- end -}} {{- if not (in (slice "sidenote" "footnote") $as) -}} {{- warnidf "tufte-bad-option" "cite shortcode: as must be sidenote or footnote, not %q; using sidenote (%s)" $as .Position -}} {{- $as = "sidenote" -}} {{- end -}} {{- /* The page locator ("p. 42", "pp. 42–45", translated: tufte/bib/locator.html), then the free postnote: both when both are given ("p. 42, emphasis added"). */ -}} {{- $post := slice -}} {{- with $pageNo }}{{ $post = $post | append (partial "tufte/bib/locator.html" .) }}{{ end -}} {{- with $noteText }}{{ $post = $post | append . }}{{ end -}} {{- $postnote := delimit $post ", " -}} {{- /* Containers whose text gets the references as a citation block. "key" $k) -}} {{- $who = partial "tufte/bib/cite-label.html" (dict "n" $n "key" $k) -}} {{- $year = printf "%v" ($n.year | default "") -}} {{- /* plainnat's extra label (1999a, 1999b) when another cited work of the scope has the same authors and year: only postprocess knows the scope, so an inert marker follows the year (tufte/bib/extra.html). */ -}} {{- with $year }}{{ $year = printf "%sTUFTEBIBXEND" . }}{{ end -}} {{- else -}} {{- warnidf "tufte-unknown-cite" "cite shortcode: unknown citation key %q (%s)" $k $.Position -}} {{- $who = printf "[%s?]" $k -}} {{- $cls = "citation-inline bib-missing" -}} {{- end -}} {{- $pn := "" -}} {{- if and $postnote (eq $i (sub (len $keys) 1)) }}{{ $pn = printf ", %s" $postnote }}{{ end -}} {{- $t := "" -}} {{- if ne $cls "citation-inline" -}} {{- /* unknown key: just the [key?] mark */ -}} {{- $t = $who -}} {{- else if eq $mode "text" -}} {{- $t = printf "%s (%s%s)" $who $year $pn -}} {{- else if eq $mode "paren" -}} {{- $t = printf "%s %s%s" $who $year $pn -}} {{- else if eq $mode "author" -}} {{- $t = $who -}} {{- else -}} {{- $t = printf "%s%s" $year $pn -}} {{- end -}} {{- $te := replace (htmlEscape $t) "TUFTEBIBXEND" (printf `` (htmlEscape $k)) -}} {{- $parts = $parts | append (printf `%s` $cls (htmlEscape $k) $te) -}} {{- end -}} {{- /* natbib's citation separator, ";", in every mode (\citet{a,b} gives "A (2001); B (1984)", \citeauthor{a,b} "A; B"). */ -}} {{- $out = delimit $parts "; " -}} {{- if eq $mode "paren" }}{{ $out = printf "(%s)" $out }}{{ end -}} {{- else if not $margin -}} {{- /* nobib: [n] linked to the list; postprocess fills the numbers. */ -}} {{- $refs := slice -}} {{- range $keys -}} {{- $refs = $refs | append (printf `` (htmlEscape .) (htmlEscape .) (htmlEscape .)) -}} {{- end -}} {{- $pn := "" -}} {{- with $postnote }}{{ $pn = printf ", %s" (htmlEscape .) }}{{ end -}} {{- $out = printf `[%s%s]` (delimit $refs ", ") $pn -}} {{- else -}} {{- $entries := partial "tufte/bib/entries.html" (dict "page" $p "keys" $keys "postnote" $postnote) | string -}} {{- if $nested -}} {{- /* Cut out by the holder (tufte/cite-gather.html) and merged into one block at the end of its note or caption. */ -}} {{- $out = printf `%s` $entries -}} {{- else if eq $as "footnote" -}} {{- /* A real footnote (SPEC-LATEX §11). Without a parent the cite may still sit in a holder that Hugo renders apart (a caption= parameter, a Markdown image title, a Markdown footnote, the text= of a note): it is emitted as a citation sidenote marked data-as="footnote", which every holder gathers into its citation block like any other; func/content-raw.html turns those left in the running text into the footnote marker ENTRIES (N: this note id's counter). */ -}} {{- $id := partial "func/note-id.html" $p -}} {{- $out = printf `%s` $id $id $entries -}} {{- else -}} {{- $style := "" -}} {{- with $offset -}} {{- with partial "tufte/offset.html" (dict "value" . "page" $p "where" (printf "(%s shortcode, line %d)" $.Name $.Position.LineNumber)) -}} {{- $style = printf ` style="%s"` (htmlEscape (string .)) -}} {{- end -}} {{- end -}} {{- $id := partial "func/note-id.html" $p -}} {{- $out = printf `%s` $id $id $style $entries -}} {{- end -}} {{- end -}} {{- partial "tufte/nest.html" (dict "ctx" . "html" $out) | safeHTML -}}
