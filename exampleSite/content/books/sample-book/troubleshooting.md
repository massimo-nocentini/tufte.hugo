## Tufte-LaTeX Website {#sec:website}

The website for the Tufte-LaTeX packages is located at
<https://github.com/Tufte-LaTeX/tufte-latex>. On our website, you'll find
links to our {{< smallcaps >}}svn{{< /smallcaps >}} repository, mailing lists, bug tracker, and documentation.

## Tufte-LaTeX Mailing Lists {#sec:mailing-lists}

There are two mailing lists for the Tufte-LaTeX project:

#### Discussion list

The `tufte-latex` discussion list is for asking questions, getting
assistance with problems, and help with troubleshooting. Release announcements
are also posted to this list. You can subscribe to the `tufte-latex`
discussion list at <http://groups.google.com/group/tufte-latex>.

#### Commits list

The `tufte-latex-commits` list is a read-only mailing list. A message
is sent to the list any time the Tufte-LaTeX code has been updated. If you'd like to
keep up with the latest code developments, you may subscribe to this list. You
can subscribe to the `tufte-latex-commits` mailing list at
<http://groups.google.com/group/tufte-latex-commits>.

## Getting Help {#sec:getting-help}

If you've encountered a problem with one of the Tufte-LaTeX document classes, have a
question, or would like to report a bug, please send an email to our
mailing list or visit our website.

To help us troubleshoot the problem more quickly, please try to compile your
document using the `debug`{{< index "debug class option@`debug` class option" >}}{{< index "class options!debug@`debug`" >}} class option and send the generated
`.log` file to the mailing list with a brief description of the problem.
(This theme's counterpart is `tufte.debug = true`, which outlines the layout
and prints extra warnings.)

## Errors, Warnings, and Informational Messages {#sec:tl-messages}

The following is a list of all of the errors, warnings, and other messages generated by the Tufte-LaTeX classes and a brief description of their meanings.{{< index "error messages" >}}{{< index "warning messages" >}}{{< index "debug messages" >}}

{{< fullwidth >}}
`Error: \subparagraph is undefined by this class.`
{{< /fullwidth >}}

The `\subparagraph`{{< index "subparagraph command@`\subparagraph`" >}} command is not defined in the Tufte-LaTeX document classes.
If you'd like to use the `\subparagraph` command, you'll need to redefine
it yourself. See the “Headings” section in the chapter
“{{< xref "tufte-book.md#sec:headings" "page" >}}” for a description of the heading styles available in the Tufte-LaTeX document classes.

{{< fullwidth >}}
`Error: \subsubsection is undefined by this class.`
{{< /fullwidth >}}

The `\subsubsection`{{< index "subsubsection command@`\subsubsection`" >}} command is not defined in the Tufte-LaTeX document classes.
If you'd like to use the `\subsubsection` command, you'll need to
redefine it yourself. See the “Headings” section in the chapter
“{{< xref "tufte-book.md#sec:headings" "page" >}}” for a description of the heading styles available
in the Tufte-LaTeX document classes.

{{< fullwidth >}}
`Error: You may only call \morefloats twice. See the Tufte-LaTeX documentation for other workarounds.`
{{< /fullwidth >}}

LaTeX allocates 18 slots for storing floats. The first time
`\morefloats`{{< index "morefloats command@`\morefloats`" >}} is called, it allocates an additional 34 slots. The second
time `\morefloats` is called, it allocates another 26 slots.

The `\morefloats` command may only be called two times. Calling it a
third time will generate this error message. See the chapter
“{{< xref "err:too-many-floats" "page" >}}” for more information.

{{< fullwidth >}}
`Warning: Option 'class option' is not supported -- ignoring option.`
{{< /fullwidth >}}

This warning appears when you've tried to use *class option* with a Tufte-LaTeX
document class, but *class option* isn't supported by the Tufte-LaTeX document
class. In this situation, *class option* is ignored. (This theme prints the
warning `tufte-bad-option` for an unknown option value.)

{{< fullwidth >}}
`Info: The 'symmetric' option implies 'twoside'`
{{< /fullwidth >}}

You specified the `symmetric`{{< index "symmetric class option@`symmetric` class option" >}}{{< index "class options!symmetric@`symmetric`" >}} document class option. This option automatically forces the `twoside`{{< index "twoside class option@`twoside` class option" >}}{{< index "class options!twoside@`twoside`" >}} option as well. See the chapter “{{< xref "clsopt:symmetric" "page" >}}” for more information on the `symmetric` class option.

The margin figure of an earlier chapter, {{< xref "fig:marginfig" "full" >}}, shows a helix; a reference like this one points backwards across chapters.

## Package Dependencies {#sec:dependencies}

The following is a list of packages that the Tufte-LaTeX
document classes rely upon. Packages marked with an asterisk are optional.

{{< fullwidth >}}
xifthen, ifpdf\*, ifxetex\*, hyperref, geometry, ragged2e, chngpage *or* changepage, paralist, textcase, soul\*, letterspace\*, setspace, natbib *and* bibentry, optparams, placeins, mathpazo\*, helvet\*, fontenc, beramono\*, fancyhdr, xcolor, textcomp, titlesec, titletoc
{{< /fullwidth >}}

This theme depends on Hugo (0.146 or newer) only; math is typeset by KaTeX,
either at build time or in the browser.
