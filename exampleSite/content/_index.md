{{< newthought >}}tufte.hugo is a theme{{< /newthought >}} for the [Hugo](https://gohugo.io) static site generator that renders your Markdown into exactly the markup [Tufte CSS](https://github.com/edwardtufte/tufte-css) expects: articles split into sections, sidenotes and margin notes,{{< sidenote >}}Footnotes written with the usual `[^1]` syntax become sidenotes automatically.{{< /sidenote >}} margin and full-width figures, epigraphs, and the ET Book typeface.

Start with the [port of the Tufte CSS demo page]({{< relref "posts/tufte-css/index.md" >}}), then read the [theme guide]({{< relref "posts/theme-guide.md" >}}) to set up your own site.
